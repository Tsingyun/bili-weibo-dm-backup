# OCR 隔离环境的依赖锁定（命令/图片与OCR/安装OCR环境.cmd 用 -r 引用本文件）
#
# 为什么要锁版本：安装脚本如果每次都拉最新版，上游被投毒或镜像被替换时会
# 静默装进能读到全部私信图片的 Python 环境（2026-09 隐私审计 M8）。
#
# 锁定基准（2026-09-22 在 PyPI 实查）：
#   · onnxruntime==1.24.1 —— 最后一个支持 Python 3.10 的版本（1.25.0 起要求 >=3.11，
#     而安装脚本固定用 Python310 的 venv，不锁版本会在未来某天直接装不上）
#   · rapidocr==3.9.2、pillow==12.3.0 —— 当前稳定版，requires_python 均覆盖 3.10
#
# 升级步骤：改下面的版本号 -> 实际跑一遍「命令/图片与OCR/安装OCR环境.cmd」
# （先删掉 .ocr-env 目录重装）-> 确认识别正常后再提交。
rapidocr==3.9.2
onnxruntime==1.24.1
pillow==12.3.0
