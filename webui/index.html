环境检查

先确认这台电脑上「用得上的东西」都齐了。缺什么下面会直接说，不影响的部分会自动跳过。

授权登录

点一下按钮，程序会用**它自己的专用浏览器窗口**打开登录页；你在那个窗口里扫码或输密码。 Cookie 只会留在本机（<数据目录>/cookie_header.txt），程序从不接触你的账号密码。

自动登录走不通？手动把 Cookie 贴进来（含逐步教程）

这条路用在「专用浏览器窗口起不来」或「本机连不上平台接口（一直显示『暂时无法校验』）」的时候。 你用自己常用的浏览器登录一次，把 Cookie 复制出来贴进下面 —— 效果和自动登录完全一样。

  1. 用你常用的浏览器打开登录页并正常登录： 微博 https://api.weibo.com/chat ；B站 https://message.bilibili.com/
  2. 登录成功后按 F12 打开开发者工具，顶部选 Network / 网络。
  3. 按 F5 刷新一次，在请求列表里点最上面那条文档请求。
  4. 右侧 Headers / 标头 → 往下找 Request Headers / 请求标头 里的 cookie: ... 一行 → 右键 → Copy value / 复制值。
  5. 整串粘进下面的框（微博必须含 SUB=，B站必须含 SESSDATA=），点「保存并校验」。

⚠ Cookie 等同于账号密码：别发给别人、别贴在群里。它只会写进本机的 <数据目录>/cookie_header.txt，程序不会外传。
