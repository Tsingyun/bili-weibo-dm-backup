# 一键安装包方案（新手零配置）

> 目标：把上手动线从「装 Node → clone/解压 → 复制 sessions.json → 填 uid → 双击」压成
> **「下载一次 → 双击一个程序 → 浏览器自动打开 → 界面里点着走完」**。

---

## 0. 结论先说

**可以做成一个整体包，而且比想象中简单。** 原因是这个项目**零第三方依赖**：

- 仓库里**没有 `package.json`**，也就没有 `node_modules`、不需要 `npm install`；
- 脚本只用 Node 内置模块（`node:http` / `node:fs` / `node:child_process` …）；
- 登录复用**系统自带的 Edge/Chrome**，不用打包浏览器。

所以「包含所需依赖与运行环境」这句话，落到实际就是**往包里塞一个 `node.exe`**：
实测 `node.exe`（v22.22.2，win-x64）= **83 MB**（87,074,816 字节），zip 压缩后经验值约 30–35 MB。

而且，**除「装 Node」之外的每一步，代码里其实已经做好了**（见下表）——
真正要补的核心只有一件事：**别让用户自己装 Node**。

|---|---|---|

## 2. 三种打包形态，怎么选

| | A. 便携一体包（zip） | B. 安装程序（单 exe） | C. 自解压单文件 |
|---|---|---|---|
| 用户拿到的 | 1 个 zip | 1 个 `Setup.exe` | 1 个 `.exe` |
| 用户动作 | 解压 → 双击 `启动.cmd` | 双击 → 向导 → 完成（可自动启动） | 双击（自解压到 `%LOCALAPPDATA%` 并启动） |
| 体积 | 约 35 MB | 约 40 MB | 约 35 MB |
| 管理员权限 | **不需要** | 视模式（per-user 可不需要） | 不需要 |
| SmartScreen | 会拦（未签名） | 会拦（未签名） | 会拦（未签名） |
| 卸载 | 删文件夹 | 有卸载器（可问「要不要保留私信数据」） | 删文件夹 |
| 实现成本 | **低（当天可出）** | 中（要写 Inno Setup 脚本 + 图标 + 版权页） | 中 |
| 适合 | 分享给同事/群友、放 U 盘 | 想让新手「像装软件一样」 | 想只发一个文件 |

**推荐：先做 A，B 作为可选升级。**
理由：A 不需要签名证书、不需要管理员、不写注册表，出问题最容易解释；
B 的体验更"像软件"，但没有代码签名证书（要花钱）时 SmartScreen 一样会拦，**体验差距没有想象中大**。

### A 的变体 A2：包里不放 node.exe，首次运行自动下载
包体降到 **< 1 MB**，启动器发现没有运行时就联网去 nodejs.org 拉官方 zip、解到 `.runtime/`，之后复用。
- 好处：包极小、升级方便。
- 代价：**首次必须联网**（且国内直连 nodejs.org 有时很慢）→ 对"下载即用"是倒退。
- 建议：**主推 A（自带 node.exe）**，A2 只作为"极小包"选项，别默认。

## 3. 方案 A 的目录结构

```
私信备份-便携版/                      ← 解压出来就这一个文件夹
├── 启动.cmd                          ← ★ 用户唯一需要双击的文件
├── runtime/
│   └── node/
│       └── node.exe                  ← 内置 Node 22（便携，不写注册表、不进 PATH）
├── scripts/                          ← 原有代码（含 lib/）
├── webui/                            ← 引导界面
├── 命令/                             ← 16 个进阶启动器（原有结构不变）
├── 文档/                             ← 本文件等说明
├── 查看备份.html
├── README.md · 使用说明.md · 使用限制.md · LICENSE
└── （首次运行后自动生成）sessions.json · data/ · bili/ · .edge-profile/
```

要点：
- `runtime/` 是**新增**的一层，只放运行时，与业务代码隔离（升级代码时可整个不碰）。
- `启动.cmd` 优先用包内 `runtime\node\node.exe`，找不到才回退 PATH / `C:\Program Files\nodejs`。
- **包内不含** `sessions.json` / `data/` / `bili/` / `.ocr-env/` / `.edge-profile/`（隐私 + 体积）。

## 4. 从「下载」到「进入 Web UI」的完整流程

### 用户视角
1. 下载 `私信备份-便携版.zip`（约 35 MB）。
2. 解压到**纯英文、无空格的路径**（例如 `D:\dm-backup`）。
3. 双击 **`启动.cmd`**。
4. 首次可能弹 SmartScreen → 点「更多信息」→「仍要运行」。
5. 出现一个黑色窗口，打印：内置 Node 版本 / 工作区路径 / 「正在启动本地服务…」。
6. **浏览器自动打开** `http://127.0.0.1:8787/`，落在第 1 步「环境检查」。
7. 之后全在界面里点，按 7 步走完。
8. 结束时回到黑窗口按 `Ctrl+C`（窗口不关 = 服务不停）。

### 系统视角（每一步到底发生了什么）

| 步骤 | 实际行为 |
|---|---|
| 双击 `启动.cmd` | `chcp 65001` → `cd /d "%~dp0"` → 校验 `scripts\` 与 `webui\` 存在 |
| 找运行时 | 查 `runtime\node\node.exe` → 回退 PATH → 回退 `C:\Program Files\nodejs\node.exe` |
| 版本门槛 | 低于 18（README 建议 22+）直接报错并说明去哪升级 |
| 起服务 | `node scripts/server.mjs --port 8787 --open` |
| 端口 | 8787 被占或被拒 → 自动 +1 重试，最多 20 次；**实际地址打印在窗口里** |
| 开浏览器 | 服务起来后用系统默认浏览器打开该地址（打不开也不影响，地址已在窗口） |
| 界面 | `webui/index.html` 第 1 步做环境自检，逐条把"还缺什么"换成可点的按钮 |

## 5. 界面里「一步一步」具体怎么走

现有 7 步（`webui/index.html:24-30`）对新手的友好度已经够，只需要把**最容易卡住的三件事**做成界面内可点：

| 步骤 | 现在 | 建议补 |
|---|---|---|
| 1 环境检查 | 展示状态 | ① **一键生成 `sessions.json`**（省掉手动 copy）；② 检测路径含中文/空格就**醒目提示**；③ 显示真实端口 |
| 2 授权登录 | 开专用浏览器窗口登录 | 缺 OCR 环境时给一个**一键安装**按钮（现只能双击 `.cmd`） |
| 3 选择会话 | 需要先填 uid | 未填 uid 时在这里**内联提示**「微博去 `weibo.com/u/数字` 抄、B站去 `space.bilibili.com/数字` 抄」 |
| 4 备份 | 已有 | — |
| 7 查看与维护 | 已有 | 提供「打开 `查看备份.html`」按钮 |

> 原则：**凡是黑窗口里能打印的提示，界面里都要能点掉**。新手不会读控制台。

## 6. 要改的代码（诚实清单）

| # | 文件 | 改动 | 风险 |

## 7. 注意事项（都是会真踩到的坑）

1. **SmartScreen / 杀软**：未签名的 `.exe`/`.cmd` 会被拦；「启动就监听端口 + 打开浏览器」这个行为特征还可能被杀软误报。
   → 文档里写清「更多信息 → 仍要运行」；介意的话只能买代码签名证书。
2. **路径别含中文和空格**：多处逻辑拼绝对路径，中文/空格会出问题。
   → 便携版应在启动器里**主动检测并拒绝启动**，而不是让用户抓瞎。
3. **端口 8787 在本机实测过 `EACCES`（保留段）**：已有自动后移，但界面必须显示**真实地址**，不能让用户照着 README 敲 8787。
4. **架构**：`node.exe` 必须是 **win-x64**；ARM 设备靠系统 x64 模拟能跑，但不保证。
5. **升级不能碰数据**：覆盖代码时必须**原地逐文件覆写**，绝不整目录删除——
   目录被浏览器/杀软持句柄时 `rm -rf` 会卡死并留下**缺文件的残包**（本项目踩过）。
6. **OCR 是唯一的大头（约 330 MB）**：不要塞进主包，否则 35 MB 变 400 MB。
   → 在界面里做「可选安装」，且它已支持「装到 `.ocr-env/`，卸载=删文件夹」。
7. **`.cmd` 编码规则**：纯 ASCII 最稳；含中文必须 UTF-8 **带 BOM**（否则 Win PowerShell 5.1 乱码）。
8. **许可要随包**：MIT 要求版权声明随副本分发 → `LICENSE` + `使用限制.md` 必须在包里
   （`build_skill.mjs` 已实现，便携包打包脚本同样要带上）。
9. **包里绝不能有 `sessions.json`**：里面有真实 uid，属于个人数据。
10. **首次运行会写盘**：`sessions.json` / `data/` / `bili/` / `.edge-profile/`
    → 若装在 `Program Files` 这类只读位置会失败，所以默认落**用户目录或解压目录**（便携包的天然优势）。

---

## 8. 不做的事（明确划界）

- 不打包 `data/` `bili/` `sessions.json`（隐私）。
- 不打包 `.ocr-env/`（330 MB，改由界面内可选安装）。
- 不打包浏览器（用系统 Edge/Chrome，Win10/11 必有）。
- 不引入 npm 依赖去"做安装器"——保持零依赖是这个项目的核心优势。

---

## 9. 落地顺序建议

1. **A 形态最小闭环**：新增包根 `启动.cmd` + `webui.ps1` 的 `Find-Node` 加内置路径
   → 手工放一个 `node.exe` 到 `runtime/node/`，先跑通「双击即用」。
2. 写 `scripts/pack_portable.mjs`，产出 `私信备份-便携版.zip`（含 `LICENSE` + `使用限制.md`）。
3. 跑回归：`verify_webui.mjs`（205）· `verify_extras.mjs`（149）· `build_skill.mjs --check`。
4. 界面第 1 步补「生成 sessions.json」「路径含中文检测」「显示真实地址」。
5. 想再进一步 → 用 Inno Setup 包一层成 `Setup.exe`（B 形态）。
