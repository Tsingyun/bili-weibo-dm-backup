# 微博 / B站 私信备份

把私信**完整**存到你自己电脑上 —— 文字、图片、表情、卡片，一样都不少，
然后做成一个**双击就能翻**的离线网页。

默认全程只在你本机跑：不存你的账号密码、不上传任何数据。
唯一的联网步骤是**可选**的「图片内容描述」—— 只把 OCR 判定**没有文字**的图片发给智谱的免费模型（含文字的截图一张都不传），详见下方「隐私与安全」。

> ⚠️ **只备份你自己有权查看的聊天记录。**
> 这是「备份我自己的聊天」，不是「爬别人的私信」。
> 用之前请花一分钟读一下 **[使用限制.md](使用限制.md)**。

`零第三方依赖` · `Node 22+` · `Windows` · `数据默认不出本机`

## 最省事的走法

**下载便携一体包 → 解压 → 双击根目录的 `启动.cmd` → 浏览器自动打开界面，剩下全在界面里点。**

> **直接下载：** [dm-backup-portable.zip](https://github.com/Tsingyun/bili-weibo-dm-backup/releases/latest/download/dm-backup-portable.zip)
> （约 33 MB · Windows 10/11）—— 这个链接永远指向最新一版。

- 包里**自带 Node 运行时**（`runtime\node\node.exe`），不用另外装任何东西，也不需要管理员权限。
- 解压到**纯英文、无空格**的路径（比如 `D:\dm-backup`）。
- 首次打开可能弹「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」。
- 会话配置已经给你建好了，对方的数字 ID 在界面第 3 步里填就行。

下面是**直接 clone 仓库**的走法。功能完全一样，只是得自己装一次 Node。

## 三分钟上手

### 第 0 步：装 Node.js（只装一次）

去 [nodejs.org](https://nodejs.org/) 下载 **LTS** 版，一路「下一步」装完就行。

### 第 1 步：把项目弄到本地

```bash
git clone https://github.com/Tsingyun/bili-weibo-dm-backup.git
```

不会用 git 也没关系：在 GitHub 页面点绿色的 **Code → Download ZIP**，解压到
一个**路径里没有中文和空格**的地方（比如 `D:\dm-backup`）。

### 第 2 步：告诉它「备份谁」

仓库**故意不带** `sessions.json` —— 一旦填上真实 ID，它就是你的个人数据了。
先从模板复制一份出来（在项目文件夹里开个命令行）：

```bash
copy scripts\_skill\sessions.template.json sessions.json
```

用记事本打开 `sessions.json`，把 `peer` 里的 `uid` 换成对方的**数字 ID**：

```json
"peer": { "uid": "1234567890", "name": "" }
```

- **微博**：打开对方主页，网址是 `weibo.com/u/1234567890` → 抄 `1234567890`
- **B站**：打开对方空间，网址是 `space.bilibili.com/1234567` → 抄 `1234567`

> 填 **uid，别填昵称** —— 昵称会改，uid 不会。
> 忘了填也能跑：程序会明确告诉你缺什么、去哪找，然后干净退出，不会静默抓成空数据。

### 第 3 步：双击开抓

进 `命令` 文件夹，按平台双击：

- **微博** → `备份与更新/更新备份.cmd`
- **B站** → `备份与更新/更新B站备份.cmd`（第一次要在弹出的浏览器窗口里扫码登录）

首次会开一个**专用浏览器窗口**（独立配置目录，不影响你平时用的浏览器），
在里面正常登录一次，之后就不用再登了。

> 嫌挑启动器麻烦？双击**项目根目录的 `启动.cmd`**，它会打开图形界面
> （等价于 `命令/查看与导出/启动WebUI.cmd`），后面按界面上的 7 步走就行。

### 第 4 步：看结果

双击项目根目录的 **`查看备份.html`**。就这样，没了。

## 不想碰命令行？用图形界面

双击**项目根目录的 `启动.cmd`**（便携包里就靠它；等价于 `命令/查看与导出/启动WebUI.cmd`），
浏览器会打开一个引导页（`127.0.0.1`），照着 7 步点就行：

> 环境检查 → 授权登录 → 选会话 → 选范围备份 → 加载别人的备份 → 导出 → 查看与维护

> ⚠️ 那个黑色命令窗口**别关**，关了服务就停了。
> 端口被占用会自动往后找，实际地址看窗口里那行「地址」。

## 它都能干什么

**备份**

- 微博、B站各存各的（`data/` 与 `bili/`），互不干扰；一份数据里可以放多个聊天对象
- 三种模式：增量（只补新的）· 全量（翻完历史）· 全量重建（按新规则重抓）
- 能指定时间范围；重建前自动留一份旧数据；索引可打快照并回滚
- 图片、GIF、表情、头像一起下
- **完整性清单**：抓完给每个文件记 sha256，之后随时能查「有没有被悄悄改掉 / 丢了」
- **漏抓对账**：拿线上最新几条和你本地对一遍，翻页被跳过的地方能发现
- **运行报告**：每次抓取都留一份小报告，失败的图片进待重试清单，下次先补它们

**看**

- 双击即开的离线网页，顶部切换「微博 / B站」
- 按天互动统计：折线图、热力图、发言节律、词云，**并能导出成一份自包含 HTML 报告**
- **媒体墙**：图片 / 动图表情 / 视频封面铺成一整面墙，按类型和「谁发的」筛选，点开看大图
- 每条消息都**按原样存档**：文字、卡片、语音、视频、表情、链接都不改写、不合并
- 单条消息可以右键隐藏（手机长按）；自动回复可一键全部隐藏
- 「一天」= 当天 **05:00 → 次日 05:00**（照顾夜猫子作息，凌晨的消息算前一天）

**搜（可选）**

- 本地全文检索（SQLite FTS5），中文能搜到，短词自动回退
- 识别图片里的文字（本地 OCR，图片不外传）
- 给「没有文字的照片」生成内容描述

**导出**

- 格式：`jsonl` · `json` · `csv` · `md` · `html` · **`html-single`（图片内嵌，单文件就能拷走）** · `bundle.zip`
- `bundle.zip` 自带 sha256 清单，对方导入时会先校验一遍；老包没有清单会明确跳过校验而不是假装通过
- 支持时间窗、按类型筛选、**一键打码**（手机号 / 邮箱 / 身份证 / 银行卡 / 地址）
- `bundle.zip` 是给人分享的：含消息 + 图片 + 索引 + 说明，对方拖进 WebUI 第 5 步就能看

**自动化**

- 定时自动更新：双击一次注册，之后默认**每周一早上 8:00** 自动跑完整链路
- 一键体检：索引与磁盘对账、js/json 一致性、图片缺失检查，能自动修
- 体检还能加两项：`--verify`（按完整性清单查文件有没有被改）· `--audit`（查有没有漏抓）

## 双击就能用的启动器

根目录的 **`启动.cmd`** 就是最常用的那一个（打开图形界面）；其余的都在 `命令/` 里，按用途分了四个文件夹：

| 文件夹 | 里面有 |
|---|---|
| `备份与更新/` | 更新备份 · 重建备份 · 更新B站备份 · 重建B站备份 · **校验完整性** · **漏抓对账** |
| `查看与导出/` | 启动WebUI · 搜索备份 · 重建搜索索引 · 索引快照 · 导出JSONL · 导出表情包 |
| `图片与OCR/` | 压缩图片 · 安装OCR环境 · 卸载OCR环境 |
| `配置与定时/` | 生成会话清单 · 注册定时更新 · 取消定时更新 |

最常点的几个：

```bash
启动.cmd                              # 图形界面（最常点这个）
命令/备份与更新/更新备份.cmd          # 微博 · 只补新的
命令/备份与更新/更新B站备份.cmd       # B站 · 只补新的
命令/查看与导出/重建搜索索引.cmd      # 数据更新后跑一次，搜索才准
命令/查看与导出/启动WebUI.cmd         # 图形界面（与根目录 启动.cmd 等价）
命令/配置与定时/注册定时更新.cmd      # 注册「每周一 8:00 自动更新」
命令/备份与更新/校验完整性.cmd        # 查备份有没有被改坏（第一次先加 --build 建清单）
命令/备份与更新/漏抓对账.cmd          # 查有没有漏抓（加 --offline 完全不联网）
```

习惯命令行的话，等价的 Node 命令：

```bash
node scripts/update.mjs --session weibo            # 微博抓取
node scripts/run_pipeline.mjs --session bili --mode incr
node scripts/build_fts.mjs                         # 重建检索索引
node scripts/doctor.mjs                            # 体检
node scripts/doctor.mjs --fix --dry-run            # 先看会修什么，再决定
node scripts/doctor.mjs --verify                   # 顺带按 sha256 清单查文件
node scripts/doctor.mjs --audit                    # 顺带查有没有漏抓（要登录态）
node scripts/integrity.mjs --build                 # 建立完整性清单（抓完全量后跑一次）
node scripts/audit_gaps.mjs --offline              # 只在本地查，完全不联网
node scripts/server.mjs                            # 起 WebUI
```

## 我的数据存在哪？

全在本机、都在项目文件夹里：

```
data/            微博：消息、图片、索引、Cookie
bili/            B站：结构与 data/ 一样
search/          检索库
exports/         导出产物
snapshots/       索引快照
_runs/           每次抓取的运行报告 + 待重试清单（在数据目录里，如 data/_runs/）
integrity.json   完整性清单（在数据目录里，如 data/integrity.json）
.edge-profile/   专用浏览器的登录态
```

> **注意**：`data/cookie_header.txt`、`bili/cookie_header.txt` 是登录凭据，**等同账号密码**。
> 别分享、别上传、别放进网盘。

## 隐私与安全（简单说）

- **数据默认不出本机**：脚本只读写本地文件，没有上传逻辑。唯一联网的是**可选**的「图片内容描述」（装好 OCR 环境并配置 key 才会启用）：只把 OCR 判定**没有文字**的图片发给智谱的免费模型，含文字的截图一张都不传；不装就完全纯本地。
- **不碰你的账号密码**：登录靠开一个专用浏览器窗口，只把 Cookie 读回本地。
- **仓库里没有你的身份**：`sessions.json`、`data/`、`bili/` 等全部被忽略。
- **WebUI 只监听 `127.0.0.1`**：同一个 WiFi 下的其它设备也访问不到。
- **导出物按「要给别人看」来设计**：支持打码，生成的 HTML / CSV 做了链接白名单与公式注入防护。
- **导入别人的备份是只读的**：抓取、OCR、压缩这类写操作对它一律拒绝。
